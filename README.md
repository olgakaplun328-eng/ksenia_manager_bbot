# Ksenia Manager Bot

Базовий Telegram-бот магазину одягу для розгортання на Railway.

## Перед запуском
- Токен, який уже публікували в чаті, вважайте скомпрометованим. У `@BotFather` виконайте `/revoke`, виберіть бота та відкличте старий токен. Використовуйте новий токен.
- Не додавайте реальний токен до GitHub, коду або README.
- Фото поки не розпізнаються автоматично.
- Рекомендація розміру за таблицями товарів ще не реалізована.
- Оплата/автоматичне надсилання рахунку не підключені.
- Це стартова версія: протестуйте її перед реальним використанням.

## Розгортання на Railway
1. Завантажте ці файли до GitHub.
2. Railway → New Project → Deploy from GitHub Repo → виберіть репозиторій.
3. Відкрийте сервіс → Variables і додайте:
   - `BOT_TOKEN` = новий токен від BotFather
   - `ADMIN_CHAT_ID` = ваш числовий Telegram ID, щоб отримувати повідомлення про замовлення (необов'язково для запуску, але потрібно для пересилання замовлень).
4. Railway використовує команду запуску з `Procfile`: `worker: python main.py`.
5. Перевірте Deployments → Logs.

## Що вміє ця версія
- Привітання й меню.
- Приймає назву/посилання товару або фото (фото лише приймається, але не розпізнається).
- Збирає зріст, мірки й бажану посадку.
- Запитує, чи клієнт хоче замовити.
- Збирає ім'я, телефон, місто й дані доставки.
- Якщо налаштовано `ADMIN_CHAT_ID`, надсилає зведення замовлення адміністратору.
