# Ksenia Manager Bot

Telegram-бот магазину жіночого одягу для розгортання на Railway.

## Налаштування
1. Відкличте старий токен у @BotFather, якщо він колись публікувався, та створіть новий.
2. У Railway → Variables задайте `BOT_TOKEN` і `ADMIN_CHAT_ID`.
3. Запустіть `worker: python main.py`.

## Поточний сценарій
- Клієнт надсилає фото або назву товару.
- Бот запитує зріст, мірки та бажану посадку.
- Після цього пропонує кнопки «Так, бажаю» / «Ні, пізніше».
- Якщо клієнт погоджується, збирає дані для доставки та пропонує повну оплату або накладений платіж із передплатою 300 грн.
- Для повної оплати надсилає реквізити ПриватБанку; для накладеного платежу — умови доставки та повернення.
- Замовлення й фото товару надсилаються адміністратору.

## Важливо
Бот не може достовірно визначити розмір лише з фото одягу. Для автоматичної рекомендації потрібні таблиці розмірів для кожної моделі та мірки клієнта; зараз бот збирає дані, щоб менеджер перевірив розмір.
